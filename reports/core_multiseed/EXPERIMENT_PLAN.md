# 核心模型三随机种子配对复验：预注册方案

## 1. 研究问题

现有 seed=0 的统一评估显示，完整 Drone-YOLO 相对 YOLOv11s 在 VisDrone2019 val 上具有更高的整体与小目标精度，同时参数量更低。本实验检验该差异能否在 seed=1 和 seed=2 下重复出现，并与既有 seed=0 组成三随机种子的成对证据。

## 2. 固定对照

| 变量 | 基线组 | 完整模型组 |
|---|---|---|
| 模型阶段 | `baseline` | `full` |
| 模型配置 | `yolo11s_baseline.yaml` | `drone-yolo11s-mffpn.yaml` |
| 初始化 | `yolo11s.pt` | `yolo11s.pt` |
| 训练轮次 | 150 | 150 |
| 新增随机种子 | 1、2 | 1、2 |
| 数据与优化 | VisDrone2019、640、batch=4、SGD、其余沿用 `paper.yaml` | 相同 |
| 验证协议 | FP32，conf=0.001，IoU=0.7，max_det=300 | 相同 |

每个种子先训练并验证基线，再训练并验证完整模型。所有训练均从 `yolo11s.pt` 独立初始化，不从另一个种子或模型继续训练。

## 3. 固定执行顺序

1. baseline，seed=1；
2. full，seed=1；
3. baseline，seed=2；
4. full，seed=2；
5. 汇总 seed=0、1、2 的统一指标和原图面积分桶指标。

当前流水线仅启动第 1 步；每一步完成且产物核验通过后才人工启动下一步。

## 4. 记录指标与判读

每个模型均记录 mAP50、mAP50-95、Precision、Recall、COCO Small/Medium/Large AP 与 Small AR，以及参数量和 GFLOPs。最终只报告每个种子的配对差值与三种子均值±样本标准差，不选择最佳随机种子。

本轮用于验证稳定性，不为验证集结果新增结构、损失或增强调参。若完整模型的正向增益跨种子稳定，才进入端到端延迟与部署复验；若不稳定，则将 LSCD 的实现假设作为后续单因素消融对象。
