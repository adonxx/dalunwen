## 4. 预注册判定

| 候选 | Small AP≥+0.30 pp | mAP50-95≥-0.10 pp | Large AP≥-1.00 pp | 无推理开销增加 |
|---|---:|---:|---:|---:|
| NWD | 否 | 否 | 是 | 是 |
| 50% Inner-WIoU + 50% NWD | 否 | 否 | 是 | 是 |

**结论：NWD和混合损失均未通过预注册条件，不建议进入150轮；应停止该损失方向或重新审视NWD用于标签分配的方案。**
