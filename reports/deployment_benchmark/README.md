## 3. 可追溯性与边界

- 每个模型均使用三个已完成训练种子；原始逐检查点结果在 `metrics/raw_runs.json`，聚合统计在 `metrics/summary.json`。
- 测试包括图像预处理、模型前向和 NMS/结果后处理，不包括磁盘 I/O、模型加载及首次初始化。
- 此处是单卡、batch=1 的框架级基准；TensorRT、ONNX 或不同 GPU 的绝对延迟需另行测量。
